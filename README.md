# 怪獣無双 ニッポン破壊録

日本の街を破壊して、そのあと建て直す 3D ブラウザゲーム。
**`index.html` 1枚だけ**で動きます。ビルド不要・外部ライブラリなし・オフラインOK。
**PC・スマホ両対応**（スマホは横持ち）。

▶ **あそぶ**: https://zau0055.github.io/monster-japan/

## あそびかた（PC）

| キー | うごき |
|---|---|
| WASD | 移動 |
| マウス | 視点 |
| Space | ジャンプ／上昇 |
| Ctrl | 下降 |
| Shift | ダッシュ |
| F | 飛行きりかえ |
| 左クリック | なぐる |
| 右クリック | 熱線 |
| Q | 咆哮（範囲攻撃） |
| G | つかむ／投げる |
| B | 建設モード |
| N | 昼夜きりかえ |
| M | BGM ON/OFF |
| Esc | ポーズ |

建設モード中は、左クリックで設置・右クリックで撤去（資源半分返却）・R で回転・ホイールと 1〜9 で選択。

## あそびかた（スマホ）

**横向き**にしてください。

- 画面の**左半分**をなぞって移動（指を置いたところがスティックの中心になります）
- 画面の**右半分**をなぞって視点を回す
- 右下のボタン … 👊なぐる ／ 🔥熱線 ／ 🔊咆哮 ／ ⬆とぶ ／ ⬇おりる ／ ✊つかむ
- 右上のボタン … ✈飛行きりかえ ／ 🏗建設モード ／ ⏸ポーズ
- 建設モード中は右下が 🏗建てる ／ 🔄回転 ／ 🧹撤去 に変わります

重いときはタイトル画面で **画質＝軽量** と **FPS上限＝30** を選んでください。
動きが止まると自動で 1fps まで落として電池を節約します。

## とくちょう

- 怪獣6体（ネズミラ 35cm 〜 ギガドラ 120m）＋ **サイズを 25cm〜300m まで自由に変更**できる
- ステージ2種：**地方都市みずなみ**（駅前商店街・瓦屋根の民家・田んぼ・送電線・国道沿い）と **大都会メガロポリス**（高層ビル・高速道路・高架鉄道・電波塔の夜景）
- 建物はフロアごとに耐久を持ち、一定割合こわすと**まるごと倒壊**する
- 瓦礫は物理でふっとび、つかんで投げられる
- 破壊で **木材・コンクリ・鉄骨・ネオン** が手に入り、建設モードで15種類を設置できる
- 生産施設（製材所・コンクリ工場・製鉄所・発電所）を建てると資源が毎秒ふえる
- 自衛隊の戦車・戦闘機が反撃してくる
- スコアは「破壊スコア」と「復興スコア」の2本立て

## 技術

- WebGL2 の自作レンダラ。世界のすべてがインスタンス描画された1種類のボックス
- 窓・瓦屋根・道路の白線・草地・水面は、すべてフラグメントシェーダで手続き的に描画（画像ファイルなし）
- 効果音とBGMは WebAudio で合成（音声ファイルなし）
- 動作が重い環境では自動で解像度を下げる
- スマホでは街の生成量とエフェクト数を自動で減らす軽量プリセットに切り替わる
- 何も動いていないときは描画を 1fps まで落として電池を節約

## 必要環境

WebGL2 対応ブラウザ（PC は Chrome / Edge / Firefox、スマホは iOS 15 以降の Safari か Android Chrome）。
まっ黒な画面が出るときは、ブラウザ設定の「ハードウェア アクセラレーション」をオンにしてください。
